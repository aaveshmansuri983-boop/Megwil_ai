# FreeLLMAPI companion setup for JARVIS V3 (Android)

FreeLLMAPI runs as a separate local service in Termux. JARVIS connects to it through
OpenAI-compatible HTTP on the same device. The gateway is not bundled into the APK.

## 1. Install Termux

Install the current Termux build from F-Droid (not the outdated Play Store build).
Open Termux and run:

```sh
pkg update && pkg upgrade -y
pkg install -y nodejs-lts git
git clone https://github.com/tashfeenahmed/freellmapi.git
cd freellmapi
npm install --no-audit --no-fund
npm run dev
```

Keep Termux running. The documented development service exposes the dashboard at
`http://localhost:5173` and the OpenAI-compatible API at
`http://localhost:3001/v1`.

## 2. Configure the gateway

Open the dashboard on the same phone at `http://127.0.0.1:5173`. Add your own
provider API keys for providers that offer free tiers, then create/copy the gateway's
unified API token. FreeLLMAPI does not generate provider keys or bypass provider
quotas. Free-tier limits, model availability, latency, and tool-calling support vary
by provider.

Do not publish the unified token or provider keys in GitHub, screenshots, logs, or
support messages. Do not expose the local development server to the public internet.

## 3. Connect JARVIS V3

In JARVIS Settings -> Hybrid AI Brain, select **FreeLLMAPI (Termux gateway)**.
The preset fills these values:

- API base URL: `http://127.0.0.1:3001/v1`
- Model: `auto`
- API key: paste the unified token generated by your local FreeLLMAPI dashboard

Save the provider, then restart JARVIS. Keep Termux and the gateway running while
using this provider. If the gateway is stopped or Android suspends Termux, online
requests will fail; the on-device Qwen provider remains the intended fallback.

## 4. Android background limits

Android may suspend Termux when it is in the background. The upstream Android guide
recommends using Termux:API, running `termux-wake-lock`, and exempting Termux from
battery optimization. These settings can increase battery use. Check the upstream
Termux guide for current instructions and limitations.

## Compatibility and security notes

- The gateway uses an OpenAI-compatible API, but JARVIS tool calling must be tested
  against the selected upstream models; compatibility is not guaranteed for every
  provider/model combination.
- This companion setup is local-device only and intended for personal experimentation,
  not a production service or a guaranteed always-on daemon.
- JARVIS currently stores configured online provider credentials in its app-private
  `providers.json` file. App-private storage is not the same as Android Keystore
  encryption. Do not use a valuable/reused password as an API token; use revocable
  provider tokens and rotate them if the device is lost.
- The JARVIS app does not install or launch Termux automatically. The user must install,
  configure, and start the companion service separately.
